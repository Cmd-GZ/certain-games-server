# 上游/玩家反馈的 bug 清单（2026-11-07）

> 来源：上游 & 玩家的实测反馈（截图里 25 条）。**验收口径：上游的游戏机制（D18）**，
> 但**不回退框架**（会话/区域/房间）—— 机制要在新架构里重新落到实处。

## 0. 已经定位到的**系统性根因**（一次解释一大批）

### 根因 A：26 种事件**从来没有被框架派发**（最严重）

重构把各游戏的监听器搬进 `GameSession#onGameEvent`，但框架只桥接了 31 种事件，
**游戏侧 instanceof 处理的却有 51 种** → 那 20 多个处理器是**死代码**。直接对应：

| 症状（反馈里的条目） | 死掉的事件 |
| --- | --- |
| OneShot 箭能被捡起 | `PlayerPickupArrowEvent` / `PlayerAttemptPickupItemEvent` |
| TNT 大战里切换副手异常 | `PlayerSwapHandItemsEvent` |
| GroupRace / SnakeParty 操作不对 | `PlayerInputEvent` / `PlayerToggleSneakEvent` / `PlayerToggleSprintEvent` / `EntityDismountEvent` |
| 天坑死亡后在虚空复活 | `PlayerGameModeChangeEvent` |
| 记忆翻牌点不动盔甲架/翻板 | `PlayerInteractAtEntityEvent` |
| 建筑猜猜乐**打字猜词没反应** | `AsyncChatEvent` / `AsyncPlayerChatEvent` |
| 密室杀手画框/盔甲架行为 | `HangingPlaceEvent` / `HangingBreakByEntityEvent` / `PlayerArmorStandManipulateEvent` |
| 一掘到底方块不掉 | `BlockPhysicsEvent` |
| 你建我跑活塞行为 | `BlockPistonExtendEvent` / `BlockPistonRetractEvent` |

**已修（MiniGameLib）**：补齐 22 种桥接 + 聊天/输入 3 种，并加了自动断言
`tools/check-event-bridge.py`（已挂进 `tools/selfcheck.sh`，漏一种就红）。

### 根因 B：公共区 / 跨区互打没有护栏

上游 `SkyPitListener#onDamageGuard`（全服玩家互伤只有"双方都在天坑"才放行）在重构时**被删掉了**，
而框架 `RegionEvents` 在"无归属（公共区）"时直接 `return` → 大厅能互砍、天坑里的人能打到主城路人。

**已修（MiniGameLib）**：`RegionEvents#onDamage` 增加规则 —— 玩家对玩家的伤害，
**只有双方属于同一个对局**才交给该对局裁决；否则直接取消（投掷物 / TNT 的玩家来源也算）。
