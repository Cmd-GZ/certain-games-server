## 4. 同世界区域相交检测

判定：两个**不同插件**的包围盒在 X/Y/Z 三轴上都相交。

**（无相交）** —— 说明现有场地在空间上确实分开了，但这只说明「当前没撞」，
不代表「不会撞」：没有任何机制阻止下一个场地建到别人头上。

## 5. 结论

1. **没有任何插件声明过「这块地归我」**。配置里只有坐标、中心点、半径，
   于是框架无法判定归属 —— I2 现在完全靠人记。
2. 能推出明确边界的场地：**14 处**；只能拿到坐标、推不出边界的插件：**14 个**。
3. 最拥挤的是 `world_mini_game`，**13 个租户**共用。对这个世界的任何「整体操作」（gamerule / 区块 / 实体扫描 / 爆炸保护）都会波及全部租户 ——
   这就是 `world_mini_game` 里那些「玩 A 游戏影响 B 游戏」类 bug 的结构性原因。
4. 要做 I2 的静态校验，第一步是给每个游戏补标准的 `ArenaRegion` 声明：
   `{ world, shape: AABB|CYLINDER, 尺寸, owner: GameKey }`，把第 3 节那些补齐。
